# Geometric Library

## Общее описание

Проект geometric_lib представляет собой библиотеку для вычисления площади и периметра геометрических фигур. Модуль circle.py содержит функции для вычисления площади и периметра круга по заданному радиусу, а модуль square.py — функции для вычисления площади и периметра квадрата по длине его стороны.

## Функции

### circle.py

#### area(r)

Принимает радиус круга `r` и возвращает площадь круга.

Пример вызова:

```python
area(2)
```

#### perimeter(r)

Принимает радиус круга `r` и возвращает периметр круга.

Пример вызова:

```python
perimeter(3)
```

### square.py

#### area(a)

Принимает сторону квадрата `a` и возвращает площадь квадрата.

Пример вызова:

```python
area(4)
```

#### perimeter(a)

Принимает сторону квадрата `a` и возвращает периметр квадрата.

Пример вызова:

```python
perimeter(5)
```
