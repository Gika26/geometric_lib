# Geometric Library

## Общее описание

Проект geometric_lib представляет собой библиотеку для вычисления площади и периметра геометрических фигур. Модуль circle.py содержит функции для вычисления площади и периметра круга по заданному радиусу, модуль square.py — функции для вычисления площади и периметра квадрата по длине его стороны, модуль rectangle.py — функции для вычисления площади и периметра прямоугольника по длине и ширине, а модуль triangle.py — функции для вычисления площади и периметра треугольника по его трём сторонам

## Функции

### circle.py

#### area(r)

##### Параметры
`r` - радиус круга, то есть расстояние от его центра до границы.

Принимает радиус круга `r` и возвращает площадь круга.

Пример вызова:

```python
area(2) # Вывод: 12,56637
```

#### perimeter(r)

##### Параметры
`r` - радиус круга, то есть расстояние от его центра до границы.

Принимает радиус круга `r` и возвращает периметр круга.

Пример вызова:

```python
perimeter(3) # Вывод: 18,849555
```

### square.py

#### area(a)

##### Параметры
`a` - длина одной стороны квадрата. У квадрата все стороны равны.

Принимает сторону квадрата `a` и возвращает площадь квадрата.

Пример вызова:

```python
area(4) # Вывод: 16
```

#### perimeter(a)

##### Параметры
`a` - длина одной стороны квадрата. У квадрата все стороны равны.

Принимает сторону квадрата `a` и возвращает периметр квадрата.

Пример вызова:

```python
perimeter(5) # Вывод: 20
```

### rectangle.py

#### area(a, b)

##### Параметры
`a` - длина прямоугольника.
`b` - ширина прямоугольника.

Принимает длину `a` и ширину `b` прямоугольника и возвращает его площадь. Площадь вычисляется умножением длины на ширину.

Пример вызова:

```python
area(3, 4)
```

Вывод: `12`.

#### perimeter(a, b)

##### Параметры
`a` - длина прямоугольника.
`b` - ширина прямоугольника.

Принимает длину `a` и ширину `b` прямоугольника и возвращает его периметр. Периметр вычисляется по формуле \(P = 2(a + b)\).

Пример вызова:

```python
perimeter(3, 4)
```

Вывод: `14`.

### triangle.py

#### area(a, b, c)

##### Параметры
`a` - длина первой стороны треугольника.
`b` - длина второй стороны треугольника.
`c` - длина третьей стороны треугольника.

Принимает длины трёх сторон треугольника `a`, `b` и `c`. Вычисляемую по формулам площадь треугольника
p = (a + b + c) / 2. Это формула для вычисления полупериметра 
S = (p * (p-a) * (p-b) * (p-c)) ** (1/2) Это формула для вычисления площади

Пример вызова:

```python
area(3, 4, 5)
```

Вывод: `6`.

#### perimeter(a, b, c)

##### Параметры
`a` - длина первой стороны треугольника.
`b` - длина второй стороны треугольника.
`c` - длина третьей стороны треугольника.

Принимает длины трёх сторон треугольника `a`, `b` и `c` и возвращает периметр — сумму длин всех трёх сторон.

Пример вызова:

```python
perimeter(3, 4, 5)
```

Вывод: `12`.
